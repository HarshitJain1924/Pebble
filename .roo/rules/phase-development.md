# phase-development

Add Zoo Code rule guidance here.

Pebble follows a phased development process.

Never implement multiple architectural phases together.

Always finish one phase before beginning another.

If a request combines multiple systems, recommend splitting it into phases.

Example:

Phase 1
Scheduling

Phase 2
Smart Folder Engine

Phase 3
Ideas

Phase 4
Inbox

Phase 5
Pinned Navigation

Keep pull requests small.

Minimize unrelated edits.

Prefer architecture-first implementation.
